# SVD-Based-Full-Spectrum-Calibration-for-Multimode-No-Core-Fiber-Sensors

1. REPOSITORY CONTENTS
----------------------

This repository contains the MATLAB codes and calibration data used for the numerical simulation, Singular Value Decomposition (SVD) analysis, calibration, and demodulation of the multimode-no-core-multimode (MNM) fiber sensor described in the associated research work.

The repository is organized into two main folders:

- MATLAB_Code: contains the MATLAB scripts used for simulation, SVD analysis, calibration, and demodulation.
- Calibration_Data: contains the calibration matrices generated for the MNM-3 sensor and used during the demodulation process.


2. MATLAB CODE
--------------

svdsystem.m

This is the main MATLAB code used to perform the Singular Value Decomposition (SVD) analysis of the spectral response of the MNM-3 sensor for the three measurands investigated in the study: curvature, axial strain, and temperature.

The program processes the experimental spectra corresponding to each measurand, constructs the data matrices required for the SVD analysis, and obtains the spectral components and normalized modal coefficients used in the calibration procedure.

The code also generates the plots corresponding to the SVD analysis presented in the manuscript and calculates the error metrics associated with the calibration.

During execution, the program generates and saves the calibration matrices for curvature, strain, and temperature as .mat files. These calibration matrices are subsequently used by demodula.m.


demodula.m

This MATLAB code is used to demodulate an experimental spectrum and estimate the corresponding measurand and its value.

The program loads the .mat calibration matrices previously generated by svdsystem.m. The user then manually selects an experimental spectrum to be analyzed. The selected spectrum is processed using the SVD-based calibration model.

The program provides:

- Identification of the corresponding measurand (curvature, strain, or temperature).
- Estimation of the measurand value.

This code therefore allows the previously generated calibration matrices to be applied to experimental spectra for parameter estimation.


simulatedmnm.m

This MATLAB code is used to numerically simulate the transmission spectrum of the multimode-no-core-multimode (MNM) fiber sensor.

The program models the multimode interference pattern generated in the No-Core Fiber (NCF) section and evaluates the spectral response as a function of the NCF section length.

The simulation was used to predict the spectral interference pattern and identify the transmission dip of interest that was subsequently analyzed during the experimental characterization. The resulting simulated spectra can be compared with the experimental transmission spectra of the fabricated MNM sensors.


3. CALIBRATION DATA
-------------------

The Calibration_Data folder contains the calibration matrices generated by svdsystem.m for the MNM-3 sensor. These .mat files contain the calibration information required by demodula.m to identify the measurand associated with a selected experimental spectrum and estimate its corresponding value.


curvature_calibration_MNM3.mat

This file contains the calibration matrix generated from the curvature analysis of the MNM-3 sensor using svdsystem.m.

The calibration information stored in this file is used by demodula.m as the reference for identifying curvature and estimating the curvature value associated with a selected experimental spectrum.


strain_calibration_MNM3.mat

This file contains the calibration matrix generated from the axial strain analysis of the MNM-3 sensor using svdsystem.m.

The calibration information stored in this file is used by demodula.m as the reference for identifying axial strain and estimating the strain value associated with a selected experimental spectrum.


temperature_calibration_MNM3.mat

This file contains the calibration matrix generated from the temperature analysis of the MNM-3 sensor using svdsystem.m.

The calibration information stored in this file is used by demodula.m as the reference for identifying temperature and estimating the temperature value associated with a selected experimental spectrum.

5. FILE DEPENDENCIES
--------------------

- simulatedmnm.m can be executed independently to simulate the MNM spectral response.
- svdsystem.m requires the experimental spectral datasets used for curvature, strain, and temperature analysis.
- svdsystem.m generates the .mat calibration matrices required by demodula.m.
- demodula.m requires the calibration matrices generated by svdsystem.m and an experimental spectrum selected by the user for demodulation.
